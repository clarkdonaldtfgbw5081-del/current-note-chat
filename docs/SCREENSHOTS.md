# Illustrated workflows: 0.15.0 and 0.14.0

[简体中文](SCREENSHOTS.zh-CN.md) · [README](../README.md)

These six browser screenshots use the corresponding version's UI/writer code, synthetic conversations and in-memory fixtures. No user notes were read and no provider requests were made. The surrounding page, modal container, theme tokens, icons and Markdown renderer belong to the demo; these images do not establish native Obsidian UI, math rendering or cross-theme compatibility.

## 0.15.0: Archive recovery and usage

![Archive tasks and usage](images/guide-tasks-0.15.0.jpg)

Saved classifications can resume writing without another provider call. Uncertain requests offer an explicit retry that may incur a charge. The task panel also supports cancellation and safe undo of recent unchanged additions. The tasks and counts shown here are synthetic.

## 0.15.0: Knowledge review plans

![Knowledge review plans](images/guide-reviews-0.15.0.jpg)

Completed Feynman rounds can schedule local reviews at 1/3/7/14-day intervals. Early practice does not advance the schedule. Start due reviews explicitly; there are no background provider calls or system notifications. Passing remains an assessment of answers, not proof of lasting mastery.

## 0.15.0: Clearer knowledge notes

![Clearer knowledge note](images/guide-knowledge-0.15.0.jpg)

The current writer omits the repeated concept heading, retains supported definitions/conditions/examples and links the provenance. Identical summary text can be deduplicated. The explicit consolidation command offers a semantic-edit preview before application. See the [implementation record](OPTIMIZATION_PROGRESS.zh-CN.md) for limits.

The following images retain the historical 0.14.0 workflows. Descriptions of that version's behavior are historical.

## Q&A and automatic archiving

![Q&A and automatic archiving](images/guide-qa-0.14.0.jpg)

The full conversation updates one note by default. A separate provider request summarizes the complete answer into a topic note within the configured knowledge folder. The folder icon opens that note. Uncertain or failed classifications go to Inbox. Classification can be disabled in settings and also stops when automatic note saving is off.

## Feynman learning

![Feynman application stage](images/guide-feynman-0.14.0.jpg)

Explain a concept, apply it to a new problem, then teach it back with a new example and limitations. This image shows the application stage. Hints do not count as a pass; the learning report is archived when the round completes. A pass is an AI assessment, not a guarantee of lasting mastery.

## Topic notes with source links

![Generated topic note](images/guide-knowledge-0.14.0.jpg)

This Markdown was generated by the 0.14.0 writer using a synthetic classification response. It includes definitions, conditions, examples and source links without internal synchronization IDs. The repeated heading is removed from new 0.15.0 notes; existing notes can be revised using the consolidation preview.
