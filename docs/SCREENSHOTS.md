# Illustrated workflows for 0.14.0

[简体中文](SCREENSHOTS.zh-CN.md) · [README](../README.md)

These browser screenshots use the current 0.14.0 widget code, synthetic conversations and an in-memory knowledge-note fixture. The surrounding page explains the workflow. No user notes were read and no provider requests were made. Demo theme tokens, icons and Markdown rendering differ from a real Obsidian installation; these images do not establish native UI, math rendering or cross-theme compatibility.

## Q&A and automatic archiving

![Q&A and automatic archiving](images/guide-qa-0.14.0.jpg)

The full conversation updates one note by default. A separate provider request summarizes the complete answer into a topic note within the configured knowledge folder. The folder icon opens that note. Uncertain or failed classifications go to Inbox. Classification can be disabled in settings and also stops when automatic note saving is off.

## Feynman learning

![Feynman application stage](images/guide-feynman-0.14.0.jpg)

Explain a concept, apply it to a new problem, then teach it back with a new example and limitations. This image shows the application stage. Hints do not count as a pass; the learning report is archived when the round completes. A pass is an AI assessment, not a guarantee of lasting mastery.

## Topic notes with source links

![Generated topic note](images/guide-knowledge-0.14.0.jpg)

This Markdown was generated by the current `KnowledgeNotes` writer using a synthetic classification response. It includes definitions, conditions, examples and source links without internal synchronization IDs in the body. Related answers currently append sections; semantic deduplication and full-note consolidation are future work. The repeated topic heading also reflects the current template rather than a finished redesign.
