# 1.0.0: the learning flow in eight illustrations

[Quick start](QUICKSTART.md) · [Project home](../README.md) · [中文说明](SCREENSHOTS.zh-CN.md)

The frames use fictional probability examples and rendered feature illustrations, not native Obsidian screenshots. Descriptions match the first-release behavior; the actual appearance follows the Obsidian theme. Click images for full size.

## 1. Ask, retain and practise

Questions become conversations and topic notes, then explanation, application and reviews help check understanding. The plugin is free; providers are configured separately and may charge.

![Ask, retain and practise](images/first-release-01-intro.png)

## 2. Ask about a file or screen

Open your material, choose a source and ask a concrete question. Screen captures are previewed before sending by default; each conversation updates one note.

![Ask about a file or screen](images/first-release-02-qa.png)

Try: “Explain independence with an everyday example and compare it with mutually exclusive events.” Use View note to open the saved conversation.

## 3. Keep asking while an answer streams

Type another question and press Enter to queue it, up to five pending items. Stop or provider errors pause remaining sends until explicit resume.

![Keep asking while an answer streams](images/first-release-03-queue.png)

The frame shows two pending questions. Items follow their source file and execute when that source is active. Screen captures occur at execution time. Queues are held in memory.

## 4. Keep questions beside the original note

Append questions, optional answers and transcript links to the asked Markdown note. Screenshots become vault PNG attachments. Source writes and conversation saving have independent settings.

![Keep questions beside the original note](images/first-release-04-source.png)

Notice the attachment, answer and conversation link. Disable Include the AI answer when appending for question-only records, or disable Append questions to the asked note to leave the source unchanged.

## 5. Organize answers by topic

Find topics only within the configured knowledge directory, preserve handwritten content and provenance, and put uncertain matches in Inbox. Classification may add AI usage.

![Organize answers by topic](images/first-release-05-knowledge.png)

Topic notes keep reusable conclusions and sources; full reasoning stays in the conversation. Configure the knowledge folder, classification model, daily limit and archive tasks in plugin settings.

## 6. Check understanding with Feynman practice

Explain in your own words, solve an application and teach it back. Feedback identifies gaps; hints do not pass stages. Check the AI assessment.

![Check understanding with Feynman practice](images/first-release-06-feynman.png)

This frame shows the application stage. Accepted explanation and application are required before advancing; hints and wrong answers do not pass. Choose direct application, transfer/reasoning or counterexamples/limits as the difficulty.

## 7. Review later and retain learning feedback

After learning, track local 1/3/7/14-day reviews and choose a topic to practise. The plan never automatically requests AI when due.

![Review later and retain learning feedback](images/first-release-07-reviews.png)

Notice the review intervals. Early practice does not advance due reviews. Disable Track spaced review plans to stop scheduling. Chosen practice uses your configured provider.

## 8. Installation and version

The directory name is Screen and File QA. First release 1.0.0 requires desktop Obsidian 1.13.0+. Use the plugin ZIP or three installation files; the source ZIP is for development.

![Installation and version](images/first-release-08-outro.png)
