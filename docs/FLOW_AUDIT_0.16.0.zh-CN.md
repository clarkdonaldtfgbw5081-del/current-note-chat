# 0.16.0 流程检查

检查范围为本地 0.16.0 更新及其与 0.15.0 保存、分类、学习、复习流程的衔接。测试使用模拟 AI 响应和独立内存仓库，不读取私人笔记或消耗实际 API 额度。

## 实际流程

1. 文件问答读取相关片段；屏幕问答在执行时截图，默认预览确认后发送。提问开始即保存到本次对话笔记。
2. 回答流式显示。普通问答期间可输入并排队最多五条问题；费曼学习仍等待本阶段评估完成。
3. 完整回答更新对话笔记。保存成功后才启动知识分类；保存失败进入已有恢复流程，停止或失败的回答不分类。
4. 独立的原笔记写回开关把问题、可选回答、对话链接追加到原 Markdown 笔记。屏幕问题绑定提交或排队时的笔记，不受等待期间切换笔记影响。截图附件保存在仓库中。
5. AI 分类只在知识目录及其子目录寻找候选。发送问答和候选名称/路径，原笔记正文不会因此额外发送；低置信度结果进入待整理，已有笔记保留手写内容。
6. 费曼学习经过解释、应用、复述三个阶段，完成后记录学习报告和本地间隔复习计划。提示、错误答案、取消请求不算通过；提前练习不推进延迟复习次数。

## 本次修复

| 场景 | 修复后行为 |
| --- | --- |
| 截图回答等待时切换笔记 | 写回提问时绑定的笔记；缓存内重试沿用原目标 |
| 原笔记或目录改名 | 写回跟随原文件对象；队列同步新路径 |
| 原文件被删除或同路径替换 | 拒绝向替代文件写回；对应排队任务移除 |
| 用户点击停止或服务商请求失败 | 保留剩余问题并暂停，主动继续后才发送 |
| 排队执行期间有未发送草稿 | 保留草稿，不被队列问题清空 |
| 附件设置不可读取 | 真正保存到问答目录下的 images，而不是引用不存在的文件夹 |
| 附件设置包含越界路径 | 不创建该附件，提示错误并保留文字问题 |
| 保存附件期间关闭写回、停用插件或移动进知识目录 | 再次检查目标和开关，阻止迟到追加 |
| 原笔记写入失败 | 显示失败提示，对话回答保留，后续写回队列可继续 |
| 空白笔记首次写回 | 从问题 callout 开始，不引入未闭合的 YAML 分隔线 |
| 每个回答单独保存 | 写回段落附上实际生成笔记的链接 |

## 验证证据

136 项自动化测试覆盖上述边界及既有的文件解析、流式协议、历史迁移、笔记格式、分类恢复、费曼评估和复习计划。新增集成回归实际串联对话保存、原笔记追加和知识归档，检查保存先后顺序、原手写内容、来源链接、公式格式及不可见标记不进入正文。

`npm run package` 执行 lint、全部测试、生产构建、版本/依赖许可检查和仅三安装文件的 PDF 解析验证，再生成插件 ZIP、源码 ZIP 与校验值。发行包不包含 `data.json`、`sessions.json`、私人笔记或本地缓存。

## 后续优化方向

- 原笔记追加目前依靠最近 200 个问题 ID 去重；可继续引入独立持久写入日志，覆盖写入成功但插件数据尚未保存时崩溃、长期 ID 淘汰和同步冲突。知识归档已有恢复日志，两者不能混为一谈。
- 截图附件保存完成但目标随后失效时，附件可能已留下。可增加附件引用检查与由用户确认的清理入口。
- 排队问题仅保存在内存，停用后清除；可增加明确选择的草稿持久化及恢复预览，避免重启后自动发送收费请求。
- 建立真实服务商的标注问题集，测量分类错误合并率、知识点覆盖和费曼误判；自动测试不能证明长期掌握。
- 在真实 Obsidian 中验证深浅主题、MathJax、附件设置、系统截图权限、多显示器及多设备同步冲突。目前的模拟测试不等于所有平台实机验证。
