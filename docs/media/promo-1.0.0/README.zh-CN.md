# Screen and File QA · 1.0.0 首发宣传片

45 秒 / 1920×1080 / 16:9 / 30 fps / 中文字幕 / 无音轨。

画面是根据 1.0.0 源码行为重新绘制的功能示意，使用虚构的概率学习内容，不是原生 Obsidian 实机录屏。每帧均标明“功能示意 · 模拟内容”。没有读取私人笔记、调用付费 AI 或使用外部音乐素材。

| 时间 | 展示内容 | 说明 |
| --- | --- | --- |

## 重新生成

`render_video.py` 是可编辑视频源文件。需要 Python 3、Pillow、imageio-ffmpeg 0.6.0，以及 Windows 微软雅黑字体。依赖当前位于上级目录 `media-tools`。

运行 `python render_video.py --preview` 生成封面、字幕与分镜预览；不加参数同时生成 MP4。导出 H.264、yuv420p，并把 MP4 索引放在文件开头以便在线播放。

字幕已经烧录在视频内，另附 UTF-8 SRT，供平台或后续剪辑使用。封面强调首发连续提问、写回原笔记与附件保存。

核实依据：项目的 `docs/FLOW_AUDIT_1.0.0.zh-CN.md`、`src/source-notes.js` 和问答队列实现。视频展示功能路径，不承诺分类始终准确或保证长期掌握。
