# 从提问到复习：1.0.0 上手指南

[项目首页](../README.zh-CN.md) · [八张功能说明图](SCREENSHOTS.zh-CN.md) · [下载安装包](https://github.com/clarkdonaldtfgbw5081-del/current-note-chat/releases/tag/1.0.0)

## 1. 安装并配置 AI 连接

需要桌面 Obsidian 1.13.0+。在社区插件中搜索 **Screen and File QA**，或下载 Release 中的 `current-note-chat-plugin-1.0.0.zip`，解压到仓库配置目录的 `plugins/current-note-chat/`，再启用插件。安装目录应直接包含 `main.js`、`manifest.json`、`styles.css`，不要多套一层文件夹，也不要使用 source ZIP 作为安装包。

打开插件设置，选择已经具备使用条件的连接方式：

| 方式 | 配置内容 |
| --- | --- |
| Codex CLI | 本机安装并登录 CLI；自动查找失败时填写可执行文件路径 |
| OpenAI / DeepSeek | 填写服务商支持的模型 ID，选择 Obsidian SecretStorage 中保存的 API 密钥 |
| 自定义兼容 API | 填写 HTTPS Chat Completions 地址、模型 ID 和可选密钥 |

先运行“检测文件问答”。想使用屏幕问答时，再运行“检测屏幕问答”；模型和接口需要支持图片输入。检测可能产生 AI 用量，图片检测使用生成的测试图，不读取你的真实屏幕。

## 2. 发出第一个问题

打开一篇学习笔记，通过左侧功能区、悬浮按钮或命令面板打开问答窗口。在“提问来源”选择“文件”，输入一个具体问题并发送。

可以尝试：

> 用一个生活例子解释这篇笔记里的独立性，并说明它与互斥的区别。

屏幕问答适合询问已经显示出来的题目或页面；发送前默认先预览截图。预览整个画面后再确认，尤其留意其他应用窗口。文件问答支持 Markdown、PDF、DOC/DOCX 和多种文本文件；长文件会选取相关片段，不保证传入全文。

## 3. 连续追问，或暂停队列

普通问答正在生成回答时，继续在输入框中打字，按 Enter 将下一个问题排队。最多保留五条待执行问题，可以逐条移除。

当前回答完成后，同一来源对话里的问题按顺序执行。其他文件的问题等待切回其来源后执行；排队的屏幕问题在执行时才截图。点击“停止”或遇到服务商错误后，队列暂停，主动继续才发送。队列保存在内存中，停用插件后清除；费曼评估期间不使用普通问答队列。

![当前回答进行中，后续问题进入可见队列](images/first-release-03-queue.png)

## 4. 查看保存结果，理解三种笔记

默认无需手动导出。同一个对话持续更新同一篇笔记，点击顶部“查看笔记”即可打开。点击“新对话”保留之前的记录，为下一次对话建立新笔记。

| 记录 | 默认位置与用途 |
| --- | --- |
| 完整对话笔记 | 中文界面默认「AI 问答」，包含原始提问、回答与学习记录 |
| 原笔记写回 | 被提问的 Markdown 笔记末尾，追加问题、可选回答和完整对话链接 |
| 主题知识笔记 | 默认「AI 知识库」，用于保存按主题归纳的内容与来源 |
| 截图附件 | 按 Obsidian 附件设置保存为 PNG；无法读取设置时使用问答目录下的 `images` |

截图问题写回时会嵌入真实保存的附件。屏幕问题绑定提交或排队时打开的 Markdown 笔记，等待期间切换笔记不会把答案写进另一篇。原笔记中的手写内容保留；「AI 问答」及知识目录内的笔记不会作为写回目标。

![问题、截图附件、AI 解答和完整对话链接写回原笔记](images/first-release-04-source.png)

## 5. 让回答进入主题知识库

完整回答的对话记录保存成功后，自动分类才开始。AI 只在设置的知识目录及其子目录中寻找已有主题笔记，使用候选名称和路径进行判断；不会为分类额外传入全部候选笔记正文。

明确匹配时把归纳内容追加到已有主题；新主题建立分类目录和主题笔记；低置信度内容进入「待整理」。从主题笔记的来源链接可以回看完整问答。原始对话仍保留，已有手写内容不会被摘要替换。

![同主题内容进入知识目录中的主题笔记，并保留来源](images/first-release-05-knowledge.png)

分类可能增加一次 AI 请求。可在设置中关闭、指定分类模型，或设置“每日分类请求上限”；默认不限制分类次数。达到上限时任务保留，可以稍后重试。关闭对话自动保存会同时停止自动分类，但原笔记写回有独立开关。

## 6. 用费曼学习检查理解

在包含知识点的文件或屏幕上，切换到“费曼学习”，输入一个具体主题并开始。

1. **自己的话解释：** 说明是什么、为什么，给一个例子；关键缺口未补齐时继续当前阶段。
2. **应用题：** 回答新的应用问题，并说明推理。难度可以在设置中选择。
3. **再次复述：** 面向初学者讲清楚，补充新例子和适用边界。

小提示帮助继续思考，不算阶段通过。AI 的反馈与判断可能出错，要对照资料核对；完成流程也不能保证长期掌握。

![解释、应用、复述三个阶段，配合反馈与小提示](images/first-release-06-feynman.png)

## 7. 到期再练一次

完成一轮学习后，记录反馈并按 1、3、7、14 天安排本地复习。在复习计划中选择知识点，再次解释或完成练习。提前练习不会推进到期复习次数。

复习计划只在本地显示，不会到期就自动请求 AI；主动开始练习时才使用配置的服务。可在设置中关闭“记录间隔复习计划”。

![学习报告和本地间隔复习计划](images/first-release-07-reviews.png)

## 常用设置怎么选

| 你的需要 | 设置 |
| --- | --- |
| 同一对话始终保存到同一篇笔记 | “笔记自动保存方式” → “每个对话一篇笔记（默认）” |
| 每个回答单独留一篇笔记 | “笔记自动保存方式” → “每次回答单独一篇笔记” |
| 只保留完整对话，不改原笔记 | 关闭“将提问写入被提问的笔记” |
| 原笔记只记录问题 | 保持原笔记写回开启，关闭“写入提问时包含 AI 回答” |
| 自己整理知识主题 | 关闭“AI 自动分类归档” |
| 限制额外分类用量 | 设置“每日分类请求上限” |

插件免费开源，AI 服务可能收费。截图、选取的文件片段、问题和近期对话会发送给配置的服务商；笔记和附件属于本地仓库数据，可能随仓库同步或备份。完整说明见[隐私与安全](../SECURITY.md)。
