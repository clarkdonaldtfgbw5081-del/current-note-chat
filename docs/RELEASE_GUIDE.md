## 图文了解 / Illustrated walkthrough

以下六张画面来自 1.0.0 首发功能示意，使用模拟内容，非 Obsidian 实机截图。实际界面跟随主题。These are rendered feature illustrations with fictional content, not native screenshots.

### 1. 屏幕或文件提问 / Ask about a screen or file

选择资料来源，输入问题。屏幕问答默认预览后再发送；同一个对话自动保存到同一篇笔记。

Choose a source and ask a question. Review screen captures before sending; each conversation updates one note by default.

![问答与自动保存](https://raw.githubusercontent.com/__REPOSITORY__/1.0.0/docs/images/first-release-02-qa.png)

### 2. 连续提问 / Queue follow-ups

回答生成时继续输入，按 Enter 排队，最多五条。停止或请求失败后暂停，主动继续才发送。

Queue up to five follow-ups while an answer streams. Stop or provider errors pause pending sends until explicit resume.

![可见的待执行问题队列](https://raw.githubusercontent.com/__REPOSITORY__/1.0.0/docs/images/first-release-03-queue.png)

### 3. 留在原笔记 / Keep answers beside their source

问题、可选回答与完整对话链接写回被提问的 Markdown 笔记，截图保存为 PNG 附件。写回与对话自动保存可以分别设置。

Append questions, optional answers and transcript links to the asked note. Screenshots become vault PNG attachments; source writes and transcript saving have independent settings.

![原笔记中的问题、附件和回答](https://raw.githubusercontent.com/__REPOSITORY__/1.0.0/docs/images/first-release-04-source.png)

### 4. 主题归档 / Organize topic notes

只在设置的知识目录内寻找主题，保留原对话与手写内容，不确定的结果进入待整理。分类可能增加 AI 请求。

Route answers within the configured knowledge directory, keep source conversations and handwritten content, and send uncertain matches to Inbox. Classification may add an AI request.

![知识目录和来源链接](https://raw.githubusercontent.com/__REPOSITORY__/1.0.0/docs/images/first-release-05-knowledge.png)

### 5. 费曼学习 / Practise understanding

自己的话解释 → 应用题 → 面向初学者复述。反馈帮助找缺口，小提示不算通过；AI 判断需要核对。

Explain → apply → teach back. Use feedback to find gaps; hints do not pass stages. Check the AI's assessment.

![解释、应用和复述阶段](https://raw.githubusercontent.com/__REPOSITORY__/1.0.0/docs/images/first-release-06-feynman.png)

### 6. 间隔复习 / Review later

完成学习后按 1、3、7、14 天安排本地复习，到期后主动开始练习；不会自动发送收费请求。

Track local 1/3/7/14-day reviews and choose when to practise. Plans never automatically send paid requests.

![学习报告与本地复习计划](https://raw.githubusercontent.com/__REPOSITORY__/1.0.0/docs/images/first-release-07-reviews.png)
